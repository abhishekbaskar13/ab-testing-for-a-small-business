# ab-testing-for-a-small-business

## About the project

We performed A/B Testing on Meta Ads to understand the impact of different ad formats on user engagement for Scones and Doilies, a local business in Lafayette, IN. We designed the test ad using the consumer behaviour theory called expectancy theory, and ran an A/B test to see if it would perform better than the control ad. There's no code involved with this project, please check out the uploaded presentation for more details on the ads and our findings.
