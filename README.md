# ab-testing-for-a-small-business

## About the project

We performed A/B Testing on Meta Ads to understand the impact of different ad formats on user engagement, based on consumer behavior theories for a local business in Lafayette, IN called Scones and Doilies. We designed the test ad using the consumer behaviour theory called expectancy theory, to see if it would perform better than our control group. There's no code involved with this project, please check out the uploaded presentation for more details on the ads and our findings.
